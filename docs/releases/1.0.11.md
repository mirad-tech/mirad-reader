# 墨读 1.0.11

发布日期：2026-10-20

## 本次更新

- **连续滚动窗口视图（Continuous Scrolling View）**：
  - 基于视口窗口化的 DOM 动态挂载机制，前后按需加载相邻章节，消除超大章节与长文档的内存压力与 WebView 掉帧。
  - 向上回滚时保持正文视口绝对锚点，零漂移、绝不回顶；完美打破短章连续死锁与反复裁剪震荡。
- **精确锚点与选区标注（CFI 与 Range 转换）**：
  - 支持 EPUB 标准 Canonical Fragment Identifier (CFI) 转换，严格校验 DOM 树节点类型与路径合法性。
  - 引入 TextQuote 多候选加权消歧与自愈算法，即便正文发生轻微变更或划线 mark 节点切分，仍能 100% 精确锚定。
- **抽象定位模型（Locator API）**：
  - 提供统一的 `Locator` 定位模型（兼容 Readium 规范），统一管理章节序号、字符偏移、进度百分比、CFI 与文本上下文选区。
- **大文件 TXT 极速流式分章与内存优化**：
  - 引入 `StreamingTxtProcessor` 流式边读边写与转码架构，采用真实物理字节边界记录（`CountingOutputStream`），内存消耗严格控制在 64KB 以内。
  - 彻底保护 Unicode 代理对与高位生僻字，内置三态换行状态机（CRLF/CR/LF），支持中文全角标点章节识别。
- **中文排版规则（避头尾法则与标点挤压）**：
  - 阅读器引入高品质中文排版引擎，遵循 CJK 标点挤压规则与避头尾法则，支持两端对齐与断词优化。
- **全书搜索性能 SQLite FTS4 倒排检索**：
  - 引入 Room FTS4 虚拟表与索引快速通道，全书搜索性能提升至毫秒级。
  - 支持 Unicode 大小写统一折叠（完美支持德法等多语言非 ASCII 变音符号不区分大小写检索），特殊通配符转义与脏索引防护。
- **网络书源与网页长文一键导入**：
  - 支持输入 HTTP/HTTPS 电子书直链（TXT/EPUB）与网页长文网址，内置 4 字节标准魔数校验与智能多级重定向跟踪。
- **全局与底层默认编码设定为 UTF-8**：
  - 未知特征或未声明编码的文本默认使用 UTF-8 进行解码，消除乱码风险。

## 安装

下载附件 `mirad-reader-1.0.11-release.apk` 安装。该包使用原有发行密钥签名，包名为 `com.mirad.reader`，versionCode 为 12，可覆盖同签名的旧发行版，无需先卸载旧版。

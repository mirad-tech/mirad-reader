# 墨读 1.1.2

版本：`versionName = 1.1.2`，`versionCode = 21`。2026-10-26 本地正式签名包，沿用原发行证书；本次不创建 GitHub Release 或标签。

## 修复与调整

- EPUB 阅读文档加入 CSP，拦截内联脚本、事件属性与 iframe，并保留阅读器脚本、样式、图片及本地补章请求。
- 导入取消或异常结束时收敛批次状态，取消后的文件与数据库补偿在不可取消区间完成。
- EPUB 资源绑定、释放及 ZIP 句柄初始化共用同步锁；阅读会话初始化失败时释放资源，避免半初始化状态覆盖已有阅读进度。
- 朗读大负载改为进程内传递，Intent 只携带请求 token。被替代的旧请求不再停止较新的播放，服务销毁与启动失败按请求归属清理负载。
- 背景设置按纯色与图片分支展示，保留独立日夜样式；图片不透明度低于 100% 时可按需调整衬底配色。阅读顶栏增加内部间距，空副标题不再占行，底栏提供自动阅读入口。
- 磨砂玻璃使用独立开关与清晰度控制；增强浅色、深色的边缘散射、暗轮廓和窄高光。首次加载或迁移玻璃偏好期间的新设置不会再被旧值覆盖。
- 修复 `gpuPreview` 对新玻璃外观构造参数的不兼容，保留该探针历史的 0% 关闭语义。

# 1.3.3

修复版本，versionCode 29。已发布到 [GitHub Release v1.3.3](https://github.com/mirad-tech/mirad-reader/releases/tag/v1.3.3)，附带签名安装包与校验文件。

## 修复

- 限制 EPUB 不可信脚本执行，保留阅读器脚本、图片、字体与样式加载。
- 修复首次恢复前覆盖阅读进度，以及恢复位移误计阅读字数。
- 修复 UTF-8 误识别、采样指纹误判重复文件、网页跨行正文遗漏、导入与重识别目录不一致、Unicode 索引搜索漏检。
- 范围重置正确双写配置，避免删除仍被引用的背景。
- 修复分组删除期间筛选状态、多选入口与取消行为、批量置顶和选择组件语义。
- 字体下载完整校验后原子发布；修正主题验收脚本。

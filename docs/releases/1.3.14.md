# 墨读 1.3.14

- 导入新版小说或重新关联文件更新原书时，默认同步为新文件的书名、作者与封面并清理旧封面；若曾在书架手动编辑过书名或作者，则保留手动修改项。
- 已标为「已读完」的连载书籍在更新续章或续读位置不在末章时自动解除已读完状态，恢复展示阅读进度。
- 增强同书匹配与续章识别：支持识别带书名号、章节区间、版本标签与作者尾缀的文件名，兼容 TXT 首章前增删简介或空行差异，以及 EPUB 首部短说明页变动。
- 打通网址直链导入与书源离线下载的同书续章原地更新；无法确认原阅读章节时维持禁止覆盖更新，修复无目录 EPUB 修订版的章首回退误判。
- 重复「导入文件夹」同步时对未改动的零拷贝书籍直接跳过全书重解析，并支持检出同路径原地等长修改。
- 补齐非书架页面的外部导入确认弹窗、阅读中收到新版导入的轻量提示、唯一候选书自动预检、更新章节明细以及同批次多版本自动归并。

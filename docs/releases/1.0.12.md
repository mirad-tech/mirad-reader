# 墨读 1.0.12

发布日期：2026-10-22

## 本次更新

- 统一暖纸色界面中的标题、字体、留白、列表、弹窗和按钮样式，改善长文本及较大系统字号下的布局。
- 统一书架、阅读器和笔记页的操作提示，增加短时淡入淡出、工具栏过渡及选中状态动画。
- 阅读弹层跟随当前阅读主题的明暗模式，避免深色正文与亮色弹层不协调。
- 导入结果按批次独立汇总并按顺序展示，避免混入上一批的成功数和错误；详细错误可按需展开。
- 完善隐藏书籍、分组管理等操作的确认和反馈。
- 阅读设置改为全书通用，减少切换书籍后重复调整字体、背景和排版的操作。

## 设置兼容性

本版统一采用全书通用阅读设置，原有单书覆盖不再优先生效。阅读进度、书签和笔记仍按书保存。

## 安装

下载 `mirad-reader-1.0.12-release.apk` 安装。包名为 `com.mirad.reader`，versionCode 为 13，使用既有正式发行证书，可覆盖同签名的旧正式版。文件校验值见附件 `SHA256SUMS.txt`。

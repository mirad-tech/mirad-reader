# 墨读 1.2.0

版本：`versionName = 1.2.0`，`versionCode = 25`。支持 Android 8.0 及以上，包名保持 `com.mirad.reader`，沿用原发行证书。

## 导航与页面

- 底部改为书架、搜书、笔记和设置四个入口，图标与文字同时显示。各入口保存页面状态和返回栈，再次点击当前入口回到首页；阅读页隐藏底栏，退出后恢复原入口。
- 搜书提供书源管理和下载列表入口；阅读统计归入设置，笔记作为独立一级入口。
- 统一标题、返回栏、操作组、列表间距和设置分组。导入集中到书架加号，批量操作收入菜单。
- 修复跨栏切换及阅读返回后的滚动位置、菜单关闭后的输入焦点，以及窄横屏输入法下的笔记输入裁切。

## 玻璃与反馈

- 导航、工具栏、菜单、消息提示、确认框和底部面板共用玻璃材质；收窄边缘过渡，减轻暗轮廓及阴影，保留圆角折射和背景透色。
- 长内容面板在高档清晰度使用统一底色，减少底图文字对前景的干扰。玻璃开关、默认清晰度 60% 和 100% 零模糊语义保留。
- 应用内导入失败、设置失败和背景读取失败接入统一反馈层；确认操作使用主按钮，危险操作使用错误色。
- 修复填充式危险确认按钮文字与底色同色的问题，并让加载态保留与进度环匹配的底色；普通禁用状态保持不可操作。

## 验证与兼容

- 549 项 JVM 单测通过；Debug/Preview/Release 构建成功，Debug 与 Release Lint 均为 0 error、46 warning、6 hint，保留既有警告。
- 改造候选的真实 Debug 包在独占 API 37 实例验证了四栏状态与滚动恢复、导入/书签、笔记保存后应用重启恢复与删除后再次重启、确认框日夜文字、取消保留及恢复禁用态。
- 正式签名的 R8 包在独占 API 37 实例完成 1.1.5 → 1.2.0 覆盖升级，测试书、阅读位置、书签和夜间外观保留。
- 隔离 Preview 完成材质、布局、输入法、模态返回与隔离、生命周期和像素回归；Preview 内存样例与真实 Debug 持久化证据分开记录。
- 生产按钮组件的隔离加载态样例另行检查日/夜主按钮和危险按钮：进度环清楚，加载中不可重复触发，取消可关闭。
- Room 表结构、已有偏好键和阅读排版引擎保持兼容；APK 中的阅读脚本与基线逐字节核对。
- 正式包的原发行证书、APK 签名、16KB 对齐、包名、版本和非 debuggable 属性均已核验。
- 当前只有 API 37 镜像，旧 API 实际运行未完成；强制降级只作为分支验证。真实手机、TTS 实际出声和第三方在线书源兼容性仍有验证缺口。

## 安装

下载同一 Release 的 `mirad-reader-1.2.0-release.apk` 与 `SHA256SUMS.txt`。正式包可覆盖同签名旧正式版；Debug 包不属于此覆盖安装保证。本机归档位于 `artifacts/apk/release/1.2.0/<批次>/`。

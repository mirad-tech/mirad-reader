# 墨读 1.3.12

- 精简书架顶栏和分组入口，调整封面和列表的进度显示。空书架可直接去搜书，隐藏书可从设置中打开或恢复。
- 笔记页改用圆角卡片，支持左滑删除和撤销。搜书采用胶囊输入框、搜索进度和带文字封面的结果卡片。
- 普通页面的内容延伸到透明系统栏后方，移除底部渐隐，保留控件安全区。
- 阅读器的笔记与书签弹层优化夜间分段配色和删除按钮布局。设置摘要单行省略，全书搜索更新初始提示。
- 书架新增独立的已读完标记。顺着读到书末或听完末章时自动标记，也可长按手动标记或取消。修复滚动中手指按住停顿后继续拖到书尾时漏记读完的问题。
- 搜书首页新增空态提示，支持一次重试上次查询中仍可用的失败书源，保留已找到的结果。

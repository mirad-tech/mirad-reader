# 墨读 1.4.0

版本：`versionName = 1.4.0`，`versionCode = 45`。支持 Android 8.0 及以上，包名保持 `com.mirad.reader`，沿用既有发行证书。

## 液态玻璃光学与渲染管线

- **统一单 Pass AGSL 透镜管线**：参考 `QWEA0/Liquid-Glass-Android` 2.0 架构，在 API 33+ 上由硬件 `RenderNode` 与 Compose `GraphicsLayer` 共用单 Pass AGSL 透镜着色器，保持既有底色浓度曲线、对比度保护语义及开关/清晰度设置不变。
- **三级形态角色与贴屏平边**：引入 `Bar` / `Panel` / `Capsule` 三级形态角色与短边自适应限幅（110dp 以下折射按平方收敛）；贴底底部弹层改为顶部双圆角并外扩底边平边（`GlassFlatEdges.Bottom`）消除底边伪亮线；底部导航选中胶囊采用窄斜面不翻折透镜并联动拖拽/按压 `press` 液态响应；背景引入非线性 Vibrancy 饱和度提纯。
- **向内透镜折射、色散与预乘归一化**：沿逐角圆角矩形 SDF 外法线向内压缩采样（逆幂斜面剖面 `falloff = 2.0`），附带 3-tap 法线方向柔化、法线 R/G/B 边缘色散及预乘 Alpha 归一化（消除贴屏边缘模糊渗黑）；100% 清晰度零模糊档位仍独立保留光学透镜与边界表现。
- **双瓣定向边缘与纸白对比**：共享同一 SDF 法线场的 30°/210° 对角双瓣镜面亮线（侧向自然归零）+ 迎光内辉光，极亮纸白背景平滑过渡出细腻折射对比轮廓；API 31–32 与 AGSL 异常路径回退至模糊 + 底色 + 单层双瓣定向渐变细边。

## 交互动效、滚动渐进模糊与次级控件

- **顶部/底部滚动渐进模糊（Scroll Edge Effect）**：非阅读页的顶/底悬浮玻璃栏间隙区域新增双层渐进模糊（`GlassScrollEdgeBlur`，复用 `HardwareGlassBackdrop` 内容节点，以 0.35× 弱模糊宽带 + 1.0× 强模糊窄带经硬件 `BlendMode.DST_IN` 线性渐变遮罩融合，单侧扩展 margin 防止贴屏侧透明黑混入），使滚动内容柔和过渡进悬浮玻璃区；清晰度 100% 或关闭玻璃时不绘制。
- **导航点击液态拉伸与玻璃按压动效**：底部导航选中胶囊在点击跨页切换时新增跨距联动的等体积液态拉伸（`computeTapLiquidStretch`，横向拉长 + 纵向微压缩 + 轻微过冲回弹）并同步增强边缘折射；书架悬浮续读卡接入触摸按压 `press` 液态反馈；阅读器顶/底工具栏呼出与收起升级为缩放 + 位移 + 淡入的液态浮现过渡。
- **玻璃面板内部次级控件通透化**：通过显式 `LocalOnGlassSurface` 作用域，仅在真正处于半透明渲染态的玻璃容器（`GlassSurface`、底部弹层、对话框、菜单）内将 `SegmentedRow`、`ChoiceChip`、`StatTile` 与内嵌 `SettingCard` 切换为半透明语义容器与柔和边框，不影响普通实色正文页。
- **动态高光开关、背景亮度复用与无障碍完善**：「界面外观 → 玻璃质感」新增「动态高光」开关（`GlassAppearance.dynamicHighlight`），开启后在非阅读页随重力传感器平滑流转边缘亮线方向（仅在绘制阶段读取 `State<Offset>` 零重组，进入阅读页、退后台、省电模式或移除动画时自动停用并注销传感器）；复用阅读硬件通路的 64px 采样支路计算 EMA 平滑背景亮度与明暗滞回（翻页保持平滑基准不闪烁），微调高清晰度（80%–100%）下的边缘高光表现，同时移除 Compose 分支闲置的 200ms 8×8 网格轮询；完整接入系统「高对比度文字」（自动退化为高可读不透明表面）与「移除动画」无障碍信号；预览入口新增 `--ez lensEnabled false` 供核验 API 31–32 双瓣渐变降级效果。

## 验证与边界

- JVM 单元测试 730 项（含 `GlassLensSpecTest` 12 项、`LiquidGlassPolicyTest` 16 项、`GlassPolicyTest` 20 项）与 Preview 单元测试 4 项全部通过。
- API 36 隔离预览模拟器完成 17 组日/夜界面、斜纹清晰度、滚动渐进模糊、弹层半透明次级控件、「动态高光」设置页及 API 31–32 降级双瓣描边视觉截图检查（零 AGSL 编译或运行异常）及 11,515 采样像素模糊与开关恢复对照。
- 本版本未执行真实目标物理机的 Perfetto 帧率基准验收，也未单独在 API 31–32 实体设备运行视觉回退验证。

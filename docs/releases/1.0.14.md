## 本次更新

- **统一全局按钮体系**：
  - 全局规范为 14sp 字号、21sp 行高、常规字重、文字居中、12dp 圆角，保持至少 40dp 视觉高度与 48dp 实际触摸无障碍目标（`minimumInteractiveComponentSize`）。
  - 主操作、次要描边、危险操作、选中、禁用及加载进度状态保持规范区分；长操作名称单行省略并保留完整语义无障碍名称。
  - 选项色圈采用 `FlowRow` 自动折行流式布局，外层 48dp 触摸范围，避免相邻高密度色块交互区域互相重叠。
  - 全面覆盖书架、阅读器各控制面板、设置、笔记、隐藏书籍、分组管理、导入及确认对话框。
- **应用级玻璃透明度控制与失败恢复（S4）**：
  - 提供“设置 → 界面外观”与“阅读设置 → 界面外观”双入口，两处实时同步同一应用级参数。
  - 提供 0–100% 玻璃透明度滑杆（默认 60%）与“恢复默认”重置能力。0% 为纯不透明底色，100% 为最大通透质感偏好。
  - 实时拖动即时响应与预览，400ms 防抖落盘，保存任务委托应用生命周期（`appScope`），脱离瞬态页面作用域。
  - 引入写入代次守卫与可见保存失败反馈：若存储写入异常，保留用户当前设置的待保存值，在“设置 → 界面外观”与“阅读设置 → 界面外观”双入口展示可见错误横幅与“重试”按钮，重试成功后自动清除提示。
- **自适应局部质感、连续保护场与 100% 明显更透明（S3 + T1 + T1.1 + T1.2）**：
  - 基于可见玻璃覆盖区域与光学模糊邻域执行有界低分辨率采样：利用单元内 $4\times 4$ 连续像素实心度探针（Coherent Solid Patch Probes，通道跨度 $\le 0.10$）精准区分高频细碎文字笔画与真实实心/准实心色块，仅包含细碎文字笔画的单元回退至页面已识别的主实心基底色（Substrate Color），彻底消除深浅主题阅读器面板与顶底栏在 100% 透明度下的误触发黑斑与明暗条带（`protectedCells == 0`）。
  - 保留真实 sRGB 通道样本并在顶/中/底三个高光位置同时校验 sRGB 通道合成与线性亮度混合双模型（目标对比度含渲染量化安全余量 `4.65:1`），确保高饱和纯蓝（`#0000FF`）、纯红（`#FF0000`）、纯绿（`#00FF00`）、深色灰底（`#AAAAAA`）以及混色局部色块下，普通与次要文字实际合成像素对比度均 $\ge 4.5:1$。
  - 彻底移除逐单元 `drawRect(Brush.radialGradient(...))` 叠加渲染，改用基于盒欧氏距离（Box SDF）的 $64\times 64$ 连续保护场单遍纹理渲染（`buildContinuousProtectionField` + `drawImage`）：在受保护单元内部及外扩 `0.42` 单元包络带内保持 100% 平坦峰值高原不衰减（保证跨单元边界与底部无高光文字处对比度恒达 `4.69:1`），外围采用五阶平滑阶跃与高斯滤波自然过渡至 `0.040` 环境通透底色，完全消除径向井字纹与矩形裁切硬边。
  - 保护增强（目标不透明度升高）立即生效无迟滞，保护释放采用 180ms 平滑过渡与微小变化迟滞（hysteresis）防抖机制。
- **跨窗口快照、在途末帧必达与全像素一致性校验（S1 + S2 + R3 + R4）**：
  - 跨窗口弹层采用事件驱动有界采样层（在 `toImageBitmap()` 读回前即将离屏 `GraphicsLayer` 限制为 $\le 25\%$ 缩放且最长边 $\le 640\text{px}$），最多 10 次/秒、单任务在途（`maxObservedInFlightCount == 1`）。
  - 分离在途采样协程（`activeCaptureJob`）与冷却尾随定时器（`trailingJob`），在途采样期间或刚结束处于 100ms 冷却期内到达的末次请求，均会在冷却期满后精确补采最新画面并更新分析缓存，且配备 `generation == token` 代次守卫。
  - 画面一致性比对采用有界位图全像素遍历二维坐标加权指纹 + 逐像素全量相等性校验，局部单像素或单网格变化均不会漏更。
  - 局部指标最多 5 次/秒并基于位置/位图缓存；从非零切到 0% 透明度、隐藏、切后台或能力降级时主动取消排队任务、使在途代次失效并清空共享快照与分析缓存。
  - API 26–30、省电模式或无硬件加速环境自动采用至少 94% 不透明安全底色，并在设置页提示简化模式状态。

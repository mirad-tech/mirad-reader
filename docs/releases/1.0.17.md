# 墨读 1.0.17

版本：`versionName = 1.0.17`，`versionCode = 18`。本地候选包已构建、签名并核验，尚未公开发布。按用户要求停止继续验证横屏键盘等边缘场景，相关限制如下。

## 本次更新

- **统一应用外观**：应用和阅读器共用“跟随系统 / 日间 / 夜间”模式，阅读背景不再反向切换应用模式。
- **分别保存日夜阅读样式**：两组独立保存阅读配色、纯色/图片背景、背景图片和图片不透明度；排版、字体和阅读位置继续使用现有配置。
- **阅读玻璃改为原生 GPU 背景**：WebView、页眉页脚及旧页动画组成内容层，工具栏和弹层单独绘制，避免玻璃重复采集自身。高透明材质配合 GPU 局部前景保护，文字与图标保持独立清晰绘制。
- **有界背景分析**：阅读 GPU 路径仅对最大边 64px 的小图进行后台分析，任务间隔至少 500ms、最多一个在途任务；分析小图不用于显示。
- **同窗口阅读弹层**：菜单、设置、搜索、笔记及确认框共用阅读控制层，处理最上层返回、IME、焦点和无障碍隔离；输入弹层保留正文测量范围。
- **COVER 硬件快照**：API 29+ 的旧页图使用独立硬件缓冲，保留覆盖翻页效果；自动翻页的截图等待纳入取消链。
- 延续本轮已有的沉浸安全区、横屏挖孔避让和设置适用性修正。

完整实现说明与证据边界见 [阅读玻璃与统一外观](../reader-liquid-glass.md)。

## 兼容与迁移

首次没有 `app_appearance_v1` 偏好时，从已保存的旧阅读配置迁移匹配的日间或夜间样式；应用模式默认跟随系统，另一组使用默认值。旧字段保留并同步，已有新记录不会重复执行首次迁移。没有新增 Room 表结构。

阅读 GPU 模糊要求 API 31+；API 33+ 的支持轮廓另启用边缘折射。API 29–30 使用简化阅读材质，但可使用 COVER 硬件快照；API 26–28 保留旧 COVER 路径。0% 透明度为不透明关闭档，硬件或内容节点未就绪时使用可读性优先的降级样式。

“零 CPU 显示捕获”指阅读 GPU 显示路径，不包含有意保留的 64px 分析读回，也不覆盖 API 26–28 的旧 COVER 路径或其他页面的既有玻璃通路。局部保护不构成对任意背景、任意文字颜色的逐像素对比度保证。

## 顶部铺满与白色光晕专项修复（重新交付）

针对首版交付后发现的顶部色带与文字/边框白晕问题，以 1.0.17（18）为基线完成定向修复：

1. **取消顶部实色覆盖**：移除 `ReaderSystemBarProtection` 贴顶不透明矩形，纯色与图片背景自然延伸至屏幕顶边。
2. **正文与控件安全区分离**：正文和页眉不再叠加状态栏与挖孔留白，不再裁剪挖孔区域文字；顶栏按钮、菜单与弹层控件继续保留原有安全区避开挖孔。
3. **彻底移除白色保护效果**：删除扩散遮罩（mask 图层）、底色染色、保护强度动画及玻璃表面外层白色渐变描边，前景直接清晰绘制，不添加替代光晕或白底。
4. **保留既有材质**：GPU 背景、模糊、轻微折射、100% 时的 2% 基础染色及正常按钮边界保持不变。

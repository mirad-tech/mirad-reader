# 墨读 1.4.1

版本：`versionName = 1.4.1`，`versionCode = 46`。支持 Android 8.0 及以上，包名保持 `com.mirad.reader`，沿用 2026-11-01 重建的发行证书，可覆盖安装 1.4.0。

## 修复

- **阅读页底部弹层**：目录、笔记、设置等底部弹层的遮罩铺满整个窗口，顶部状态栏区域与其余部分一起变暗；面板一直延伸到屏幕底边，不再在手势条上方留出一条未变暗的正文。键盘弹出时面板仍让到键盘上方。所有使用 `GlassInWindowSheet` 的弹层同步生效。
- **全书搜索区分大小写**：此前库内候选用 `LIKE`，区分大小写时仍不分英文大小写，再由 Kotlin 侧过滤，且结果上限在过滤前截断，极端情况下会漏结果；现改为 `instr` 精确比对。

## 存储

- **搜索缓存改为普通表**：原 `chapters_fts` 为 FTS4 虚拟表，中文无分词，倒排索引从未被查询使用，且原文与大小写折叠后的正文各存一份。现改为普通表 `chapter_search`（主键 `bookId, chapterIndex`），折叠正文仅在与原文不同时保存。
- 数据库版本 3 → 4：升级时删除旧搜索缓存（只是可重建的缓存，不影响书籍、进度、书签、划线和设置），各书在下次搜索时重新建立。启动约 15 秒后检查一次空闲页，超过 4 MB 时执行一次 `VACUUM` 回收空间。
- **不能降级**：升级到 1.4.1 后再安装 1.4.0 或更早版本，打开时会因数据库版本降级而崩溃，须卸载重装（会清除本地数据）。

## 内部调整

- 数据层不再依赖界面层：封面失效改走 `data.CoverInvalidation`；`GlassAppearance` 及其 JSON 编解码移至 `core.model`，偏好键与格式不变。
- `ImportPipeline` 拆出 `BookPreparer`（TXT / EPUB 解析）、`ImportSourceIo`（来源读取与复制）、`EditionReviewCoordinator`（同书新版核对与替换），行为不变。
- 界面状态订阅改为 `collectAsStateWithLifecycle`，退到后台时不再收集 Room 查询流。
- 新增 `-PcomposeReports=true` 构建开关输出 Compose 编译器稳定性报告；新增 `tools/verify.ps1` 一键运行单测、preview 编译与 Debug 构建并保存日志摘要。

## 验证与边界

- `tools/verify.ps1`（2026-11-22 15:57，`build/verification/verify-20261122-155702/`）：JVM 单元测试 730 项全部通过，preview 源集编译与 Debug 构建通过。
- 迁移 SQL 与 Room 生成的 `app/schemas/.../4.json` 建表语句逐字一致。
- 本版本未在隔离模拟器上做截图验证：底部弹层的视觉效果、3 → 4 实机迁移、`instr` 搜索结果与 `VACUUM` 执行情况尚无 Android 设备证据。
- Release 签名包由 `tools/package-release.ps1` 生成，输出位于 `artifacts/apk/release/1.4.1/<批次>/`。

# 墨读 1.0.10

发布日期：2026-10-20

## 本次更新

- 新增自动阅读：分页模式定时翻页，上下滚动模式匀速下滑，速度可调，每本书分别记住设置。
- 自动阅读支持暂停、继续和关闭；触摸正文、打开菜单或进入后台时暂停，重新打开书籍默认关闭。
- 优化上下滚动：手动拖动接管程序滚动，减少动画争抢位置；到达章末后继续滑动才手动接章。
- 菜单显示时，点击工具栏之间的正文区域只收起菜单，不再触发翻页；左右两分模式保留菜单入口。
- 修正长段落阅读锚点，改善调整字号及重新打开书籍时的位置恢复。
- 接通外部应用分享、打开 TXT/EPUB 文件的导入入口，改善朗读引擎首次初始化的播放衔接。
- 包含此前本地版本的音量键翻页、TXT 数字章节识别和滚动换章改进。

## 安装

下载附件 `mirad-reader-1.0.10-release.apk` 安装。该包使用原有发行密钥签名，包名为 `com.mirad.reader`，versionCode 为 11，可覆盖同签名的旧发行版。无需先卸载旧版。

附件 `SHA256SUMS.txt` 提供安装包校验值。

## 已知限制

- 自动接章请求已经发出时，暂停后仍可能完成这一次换章。
- 从暂停的朗读切换到自动翻页，跨章时可能受到旧朗读位置影响；使用自动阅读前可先停止朗读。

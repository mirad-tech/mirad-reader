## 3 实质精简内容

- **TXT 分章**：普通读取与流式读取共用章节区间生成，保留各自读取方式、真实字节偏移和无标题兜底；新增一致性测试覆盖前言、分卷及多字节字符。
- **公共交互**：合并按钮加载内容、Markdown 文件写出、字体导入/刷新/删除流程，保留各入口的内容范围、提示及配置就绪时机。
- **阅读引擎**：合并文本节点遍历、标注区间计算和标记移除；清理确认没有调用入口的旧定位函数。
- **原生会话**：共用可取消的脚本结果处理；分离记录与样式职责，减少重复高亮负载构造和单纯转发的私有中间层。
- **无用代码**：经源码、测试、预览及资源入口核查，删除未使用的 DAO/repository/UI 封装、重复构造器和无人读取的扫描元数据。
- **收尾清理**：10 个一次性改写脚本已删除，本次检查未发现这些脚本遗留。验证证据和持续使用的 `reader-source.cjs` 保留。

JS 在源码层分文件维护，构建时仍输出一个 `assets/reader/reader.js`，运行时保持同一闭包和原加载路径。29 个 JS 对外方法保持不变，三个构建类型的脚本与浏览器测试输入一致。

Room 表结构、外观迁移与旧键双写、设置写入防抖和锁、桥接回调别名、音量键/自动阅读/TTS 释放链均按原行为保留。COVER 位移继续在绘制阶段读取，避免拆分引入每帧整页重组。本轮没有宣称或证明运行性能提升。

# 墨读 1.1.5

版本：`versionName = 1.1.5`，`versionCode = 24`。支持 Android 8.0 及以上，沿用原发行证书，包名保持 `com.mirad.reader`。

## 书源、搜索与下载

- 新增书源管理：从 URL 导入单个或多个阅读类 JSON 书源，保存原始链接及规则，支持筛选、启停、删除和重新获取；刷新失败保留原规则。
- 新增全源搜书：逐步展示结果，按书名和作者归并；选书后读取各来源的完整目录，按实际去重章数排序，默认前五，可展开全部及查看目录，失败来源单独显示。
- 新增后台整本下载：支持暂停、继续、取消和重试，按章保存断点；成功入库后生成可离线阅读的 EPUB，保留书名、作者和章节顺序。拒绝通知权限时仍可在下载页控制任务。
- 书源规则在隔离进程内执行；限制脚本时间及输入输出，支持规则超时后的恢复。健康连接会复用，并在空闲后释放。
- 保留原有 TXT/EPUB 文件、直链和单篇网页导入；不改变 Room 表结构或已有阅读配置。

## 修复与代码整理

- 修复同一 URL 通过不同 POST 请求体分页时误报重定向循环；按实际请求区分分页，保留真实循环检查。
- 在逐页合并正文时检查累计 UTF-8 大小，计入页间换行，超过现有 8MB 章节上限立即停止。
- 修正 Android 正则模板兼容、隔离规则通信，以及下载停止、恢复和入库取消时的任务交接。
- 保留 Release 缩减后所需的 Rhino 解释器入口，并处理未开放的桌面 JavaBean 转换依赖。
- 包含未单独公开发布的 [1.1.4 代码整理](1.1.4.md)：按职责拆分阅读器与玻璃组件，共用文本和配置处理逻辑，阅读脚本仍由同一源码入口生成。

## 验证范围

- 新版本的 542 项 JVM 单测通过；`lintDebug` 为 0 error、46 warning、6 hint，保留既有 warning。
- 正式签名、R8 压缩候选在独占 API 37 模拟器上完成 1.1.4 → 1.1.5 覆盖升级，旧书及第 4 章阅读位置保留。
- 正式候选完成书源导入、多源搜索、完整目录排名、后台锁屏下载和离线 EPUB 阅读；JavaScript 正则替换、JSONPath 以及死循环规则超时后的恢复通过。
- APK 内的阅读脚本与浏览器源码拼接结果逐字节一致；正式证书、APK v2/v3 签名、16KB 对齐、包名、版本和非 debuggable 属性均已核验。
- 设备验收使用自造受控书源；实际第三方书源兼容性、API 26–33 的 WorkManager 分支、真实手机与 TTS 实际音频未完成本轮设备验证。此前版本记录的其他验证缺口仍按原范围保留。

## 兼容与安装

首版支持常用阅读书源规则与基础文本脚本，不支持登录/验证码交互、WebView 动态页面、外部脚本、漫画/音频书源或自动追更。不同来源的分章方式可能不同，章数不等同于内容质量。详细范围见[书源说明](../BOOK_SOURCES.md)。

下载同一 Release 的 `mirad-reader-1.1.5-release.apk` 和 `SHA256SUMS.txt`。正式包使用原发行证书，可覆盖同签名旧正式版；Debug 包不属于此覆盖安装保证。安装包和签名核验记录保存在本机 `artifacts/apk/release/1.1.5/<批次>/`。

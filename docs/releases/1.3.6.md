# 墨读 1.3.6

- 续读改为底部非模态玻璃浮卡，默认显示 5 秒；关闭或超时后本次应用会话不重复提示。
- 导入进度共用浮卡位置并优先显示，区分复制与解析阶段，避免被底部导航遮挡。
- 接入完整 GB2312 界面衬线字体，优化无封面书籍、设置摘要、背景文字预览、图标及搜书布局。
- 修复笔记导出禁用颜色、阅读工具栏边缘衔接和页眉与正文重叠。
- 全屏保持既有正文排版；非全屏让页眉和正文共同避让顶部安全区，可能重新分页。关闭页眉时页脚仍固定在底部。
- 保留玻璃策略、阅读默认字体和排版配置，不修改 Room 或阅读引擎。

验证：UI 主变更通过 637 项 JVM 测试；页眉后续修复通过 10 项定向测试。API 36 项目隔离模拟器已验证浮卡、真实导入、玻璃采样、分页顶部布局和页脚位置，实例已清理。旧版 Android 与真实设备未测试；窗口模式切换的几何验证使用现有预览配置通道。

发行前复核：639 项 JVM 测试通过，0 失败/错误/跳过；Lint 为 0 错误、37 个既有警告。Release 已完成 R8 压缩、发行证书校验、16KB 对齐与非 debuggable 校验。此前原生证据针对 Debug/Preview，本次未新增 Release 安装实测。

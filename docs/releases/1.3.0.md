# 墨读 1.3.0

版本：`versionName = 1.3.0`，`versionCode = 26`。支持 Android 8.0 及以上，包名保持 `com.mirad.reader`，沿用原发行证书。

## 导航与顶部

- 一级和二级页面统一整条悬浮玻璃顶栏，标题与实际存在的副标题整体垂直居中，不再用空白行强制对齐。
- 底栏使用单个连续移动的玻璃胶囊。长按后推动，正文同步横向移动；松手吸附最近页面，保留各入口的返回栈、搜索和滚动状态。
- 修复底栏胶囊高度反馈增长、切页时玻璃背景采样滞留，以及输入法与弹窗关闭后导航未恢复的问题。

## 玻璃与阅读资源

- 菜单、目录、阅读设置、确认框和消息在高档清晰度保留柔和模糊，不再通过近乎不透明的底色遮挡正文。
- 弹窗仅把模糊档位限制在80；底色仍随原清晰度减薄。导航与阅读工具栏在100时仍零模糊，并使用统一底色下限区分前景控件与正文；原有玻璃开关、默认60与保存值保持兼容。
- 新增内置 Noto 黑体、朱雀仿宋，保留原默认文楷。字体许可、覆盖及回退说明随资源提供。
- 新增日间纤维纸、雾青纸，以及夜间墨青、炭灰背景。低对比植物线描按常见长屏裁切保留在边角；日夜背景分别保存。

## 书源文件导入

- 加号菜单支持链接和文件两种导入入口；完整书源对象/数组与链接清单分别解析。
- 支持 UTF-8/BOM 文件、逐行网址、JSON字符串数组和 `{"urls":[...]}`，文件上限8 MiB。只抓取顶层清单，不抓取完整规则内部的搜索或封面网址。
- 清单去重、部分失败继续导入，取消时保留已完成结果；重新导入保留启用状态及已有网络订阅。
- 导入规则不代表站点可用或完整兼容。第三方登录、脚本等限制仍见[书源说明](../BOOK_SOURCES.md)。

## 阅读页数与位置

- 修复部分设备小数视口下，分页容器实际宽度与整数列宽不一致，导致短章多算出一页、翻页正文不动的问题。此时保存的是正文末尾偏移，重新打开会回到实际首屏，看起来像进度归零。
- 分页容器与版心使用同一列宽；保留原有末列取整与字符定位算法，不通过删页或延迟初始化掩盖问题。
- 新增窄屏和宽屏限宽的3组浏览器回归：短章不能进入虚假末页，真实长章冷打开恢复保存字符，真实末列仍可达。

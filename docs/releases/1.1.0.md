# 墨读 1.1.0

版本：`versionName = 1.1.0`，`versionCode = 19`。本地正式包已构建、签名并核验。

## 本次更新

- **设置页信息架构重构**：阅读设置与应用设置分路由管理；「屏幕与信息」拆分为「屏幕」与「页眉页脚」两页；阅读面板不再混入应用级入口，统一收纳到设置页「应用设置」。
- **阅读面板快捷调节**：面板首页新增日夜模式快捷切换与当前组主题色板，连同阅读方式分段、字号一起放在最顺手的位置；窄屏大字体下依然一眼可达。
- **恢复默认分范围**：新增多选对话框（排版与交互 / 日间配色 / 夜间配色），设置页与阅读面板共用；只重置勾选范围，其余设置原样保留。
- **书架布局记忆**：网格 / 列表切换会被记住，不再每次回到书架都重置为网格。
- **阅读工具栏加宽**：顶部返回/章节名/收藏行与底部玻璃面板整体加宽加厚，更贴近全面屏边缘。
- **排版新选项**：字间距滑块（0–0.30em）；音量键翻页可关闭（关闭后音量键交还系统）；自动阅读速度滑块进入「翻页与交互」页。
- **页眉显示章节名**：页眉标题改为显示当前章节名（原来显示书名），开关文案同步为「显示章节名」。
- **正文连续标点重合修复**：移除 WebView 的 CJK 标点压缩特性（chws/halt），「？！」等连续全角标点不再叠印；字体与两端对齐已排查排除。
- **EPUB 保留原书置灰**：原书版式下「字体」「排版」卡照常显示但整体置灰停用，保留页边距、版心与跳转入口。
- **数据与维护加固**（延续本轮多轮审查）：正文替换失败后的文件与数据库一致性保障（ReindexCoordinator 备份回滚）；新旧外观配置都成功持久化后才清理旧背景图；设置页分组管理改用统一弹层；外观页保存失败合并为一条横幅、一个重试。
- **模型清理**：移除废弃配置字段与 `CURL` 翻页动画（旧数据自动收敛）；删除书级配置遗留 API，启动时一次性清理 `reader_config_book_%` 遗留键。

## 兼容与迁移

- 旧版本落库的阅读配置 JSON（含已删除字段或 `pageAnim=CURL`）解码安全：未知字段忽略，非法翻页动画收敛为滑动。
- `reader_config_book_%` 遗留键在启动时一次性删除（幂等，带完成标记），不影响其它偏好。
- `windowedScroll` 配置字段移除：滚动模式一律启用 3 章滑动窗口（与此前默认行为一致）。
- 阅读面板的「界面外观」入口移入设置页；玻璃质感与日夜模式的完整入口在设置 → 应用设置 → 界面外观。
- 无 Room 表结构变化。

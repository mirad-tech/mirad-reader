# 墨读 1.3.1

版本：`versionName = 1.3.1`，`versionCode = 27`。支持 Android 8.0 及以上，包名保持 `com.mirad.reader`，沿用原发行证书。

## 上下栏恢复通透磨砂

- 修复主页与阅读页顶部、底部玻璃看起来像一块白底的问题。原因是五处调用点给整栏底色加了 66%（日间）／78%（夜间）的不透明度下限，材质层再取最大值，即使背景采样、模糊和折射都正常，也只能看到一块主题底。
- 底色改由公共策略按角色决定：上下栏（公共顶栏、应用底栏及其选中胶囊、阅读顶／底栏）在清晰度 0 时为日间 46%／夜间 52%，默认 60 为 14.1%／16.7%，100 为 8%／10%。封面、插图与正文经过栏后能连续透出颜色与结构。
- 材质层不再接受调用点传入的整栏不透明度下限（`minimumTintAlpha` 已移除），避免下次调整又只修到一处。
- 清晰度 0 仍是最朦胧的一档（模糊半径最大），不等于关闭；玻璃开关关闭仍是不透明稳定表面，GPU 不可用仍走 94% 降级底，两者语义不变。
- 弹窗不再单独把模糊档位限制在 80：目录、设置、消息与确认框和上下栏共用同一套 0–100 语义，100 档同样零模糊，底色继续按面板曲线减薄。按此设置，100 档在繁忙背景上看不清文字属已知取舍。

## 验证与边界

- 566 项 JVM 单测 0 失败；Debug Lint 为 0 错误、48 警告、6 提示（存量警告未处理）；Release 版 `lintVitalRelease` 通过。新增底色彩度与档位的数值锁定测试，改动数值必须重新走界面验收。
- 真实 Debug 页面（API 37）用带彩色封面与内嵌插图的 EPUB 对比：封面经过时顶栏内彩度由 21.8 升到 58.2，背景结构可见；硬件阅读场景实测 `baseOpacity` 由 0.66 降到 0.1408（夜间 0.1672），0 档 0.46／17.5dp，100 档 0.08／0dp，`gpuActive` 与折射均正常、无降级分支。
- 预览矩阵前后各 21 例：书架与阅读 × 日／夜 × 清晰度 0／60／100，另加玻璃关闭、强制降级、弹窗日／夜与 100 档、阅读设置页。底栏长按拖动仍跟手跨四个入口并吸附；阅读位置在 HOME 往返与强停重开后保持。
- 已知限制：深色主题叠在高亮封面时，栏内小字对比度约 3:1（标题大字可辨，副标题偏低），是薄玻璃与固定主题前景的固有取舍；只有 API 37 镜像，未在 API 26–30 实测。
- Room 结构、偏好键、阅读配置与分页引擎未改；本次只改玻璃底色策略与相关测试。

# 墨读 1.0.16

发布日期：2026-10-24  
版本：`versionName = 1.0.16`，`versionCode = 17`

## 更新内容

- 新增应用级玻璃透明度设置，范围 0–100%，默认 60%。全局设置和阅读设置共享同一个值，支持实时调整、恢复默认，以及保存失败后的提示与重试。
- 为顶栏、菜单、对话框和底部面板接入玻璃外观，调整 100% 时的通透效果，并将局部保护改为连续绘制，修正已复现的规则网格与条带问题。
- 改进背景采样的末帧补采、画面一致性判断、跨窗口共享及关闭后的资源清理。
- 统一常用按钮的排版、圆角与触摸目标，调整大字号和长文字场景的布局。
- 改进字号变化、连续滚动与章节切换时的位置保持，并补充相应回归检查。

## 已知问题与验证边界

- 高透明度下，细密纹理背景中的普通或次要文字仍可能对比度不足；部分使用墨绿或危险色的操作文字也尚未纳入统一保护计算。需要稳定可读性时，可将玻璃透明度设为 0%，使用不透明底色。
- 部分开发预览中，阅读菜单和章节面板的场景覆盖尚未完成；验证脚本续跑时对旧截图的 APK 来源关联也仍需修正。本版本不声明已通过完整原生界面验收。
- JVM 和 Chromium 检查不能替代 Android 设备测试。真实旧系统、物理手机、完整字体/方向矩阵和真实 Room 写入故障恢复不属于本次发布验证的已覆盖范围。
